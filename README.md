## Requirements
[WindowsGSM](https://github.com/WindowsGSM/WindowsGSM) >= 1.23.1

## Installation
1. Download `WindowsGSM.Dragonwilds-<version>.zip` from the [latest release](https://github.com/JoshKociemba/WindowsGSM.Dragonwilds/releases/latest).
1. In WindowsGSM, import the zip from the Plugins tab without renaming it, or extract the **Dragonwilds.cs** folder into the **plugins** folder.
1. Click **[RELOAD PLUGINS]** or restart WindowsGSM.
1. Install a new server and pick **RuneScape: Dragonwilds Dedicated Server**.

## First start
The server will not start until you set your Owner ID and replace the placeholder admin password. Until then, starting it shows:

```
[ERROR] Set OwnerId in ...\RSDragonwilds\Saved\Config\WindowsServer\DedicatedServer.ini to your Player ID (bottom of the in-game Settings menu)
```

To fix it:
1. **Find your Player ID.** Launch the game, open **Settings** and scroll to the very bottom. Your Player ID is shown there. It is not your Steam ID or Jagex account name. The game itself requires this value: the server won't start without it, because it marks you as the owner.
1. With the server stopped, select it in WindowsGSM and open **Browse => Server Files**, then `RSDragonwilds\Saved\Config\WindowsServer\DedicatedServer.ini`.
1. Replace the `CHANGEME` values with your Player ID and an admin password of your choice (or delete the `AdminPassword` line), then save and click **Start**.

```ini
[/Script/Dominion.DedicatedServerSettings]
OwnerId=CHANGEME
ServerName=WindowsGSM - Server #1
DefaultWorldName=Dragonwilds
AdminPassword=CHANGEME
WorldPassword=
PlatformPolicy=Crossplay
```

| Key | What it is |
|---|---|
| `OwnerId` | Your Player ID (not your Steam ID), shown at the bottom of the in-game Settings menu. Required. The owner can ban and unban anyone. |
| `AdminPassword` | Unlocks Pause Menu > Settings > Server Management in game. Admins can ban online players but can't unban. Optional. The server removes this line from the file every time it starts, so the plugin saves a copy in `serverfiles\AdminPassword.txt` and puts the line back before each start. To change it, edit the line in the ini again. To remove it, delete `AdminPassword.txt` as well. The server won't start while it's still `CHANGEME`. |
| `WorldPassword` | Password to join, letters and numbers only. Leave empty for a public world. Overrides any password saved in the world. |
| `PlatformPolicy` | Who can join: `Crossplay` (default), `PC`, `PlayStation`, `Xbox` or `Nintendo`. |
| `ServerName` | Copied from the WindowsGSM **Server Name** on every start. Keep it to 32 characters; the public list only shows the first 16. |
| `DefaultWorldName` | Copied from the WindowsGSM **Default Map** on every start. Keep it to 20 characters. Only used when no world save exists; on startup the server loads the newest save in `Saved\Savegames`. Players search for this exact name (case sensitive) in the Public tab. |
| `ServerGuid` | Generated by the server. Don't edit it. |
| `bAllowSendingCrashDumps` | Added by the server. `True` sends crash reports to Jagex; set it to `False` to opt out. |

The plugin checks these before every start and shows an error in WindowsGSM if a required value is missing or invalid.

Only edit the file while the server is stopped, or the server overwrites your changes. The server also rewrites the file itself when it starts, adding a `;METADATA` line and `bAllowSendingCrashDumps`, and removing `AdminPassword` (which the plugin restores). The plugin leaves every other line, including `ServerGuid`, untouched.

## WindowsGSM settings
- **Port**: UDP game port, 7777 by default. A second server uses 7778.
- **Max Players**: passed to the server on launch. Dragonwilds allows up to 6, and higher values are lowered to 6.
- **Start Param**: extra launch arguments, `-log -unattended -NoCrashDialog` by default, so a crash exits cleanly and Auto Restart can bring the server back.
- **Embed Console**: supported. Stop sends Ctrl+C and waits up to 60 seconds for the world to save before the process is killed.

## Port forwarding
Players outside your network need the game port forwarded to the PC running the server.

1. **Check the port.** Use the port shown for the server in WindowsGSM. The default is 7777, but if 7777 is already taken, for example by another server, WindowsGSM picks the next free one (7778, 7779 and so on). Either forward that port, or change it in **Edit Config** while the server is stopped.
1. **Find the PC's address.** On the server PC run `ipconfig`. The **IPv4 Address** (e.g. `192.168.1.50`) is where the port goes, and the **Default Gateway** is your router's admin page. Open it in a browser.
1. **Add the forward on the router.** Use the protocol **UDP** (not TCP) and the game port as both the start and end of the port range. Set the internal IP to the PC's IPv4 address, and the same address for start and end if the router asks for an IP range.
1. **Keep the address fixed.** Reserve that IPv4 address for the PC in the router's DHCP settings, so the forward keeps working after a reboot.

WindowsGSM adds the Windows Firewall rule for the server exe the first time it starts. If players still can't connect, add one yourself in an admin PowerShell (change the port if yours differs):

```powershell
New-NetFirewallRule -DisplayName "Dragonwilds Server UDP 7777" -Direction Inbound -Protocol UDP -LocalPort 7777 -Action Allow
```

The server also listens on **UDP 8888** for what its log calls a world settings beacon. Joining works with it closed, so you don't need to forward it.

Players don't need your IP or port to join. The most reliable way is the world's **join code**, which the server writes to `RSDragonwilds\Saved\Logs\RSDragonwilds.log` on every start (search the log for `JoinCode`). Players can also search for the exact world name (case sensitive) in the **Public** tab of the Worlds screen. Direct connect by IP may fail with "Network connection was interrupted" even when the join code works.

## Move an existing world
1. On the PC you play on, find the world in `%LOCALAPPDATA%\RSDragonwilds\Saved\SaveGames`. Each world is one `.sav` file named after it.
1. Stop the server and back up its `RSDragonwilds\Saved\Savegames` folder.
1. Copy your `.sav` into that folder.
1. Set **Default Map** in WindowsGSM to the file name without `.sav`, since the server loads the save that matches it, then start the server.

Characters aren't part of the world. They stay on each player's PC and join with them, so there's nothing else to copy. Map markers for some things you found locally, like Sanguine Urns, may not show on the server.

## Files to back up
- World saves: `WindowsGSM\servers\%ID%\serverfiles\RSDragonwilds\Saved\Savegames`
- Server config: `WindowsGSM\servers\%ID%\serverfiles\RSDragonwilds\Saved\Config`
- WindowsGSM config: `WindowsGSM\servers\%ID%\configs`

Back up your saves before updating the server.

Server logs are in `RSDragonwilds\Saved\Logs\RSDragonwilds.log`. The server version is at the top of the log and must match the game client version shown in the top-left corner of the game.
